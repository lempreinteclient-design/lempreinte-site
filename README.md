# L'empreinte, site internet

Site vitrine de L'empreinte (merch sur mesure pour BDE, lycées, associations, bars et entreprises).

- `index.html` : la page d'accueil (présentation, étapes, techniques, produits, formulaire de devis)
- `merci.html` : la page affichée après l'envoi d'une demande de devis

Le site est hébergé sur Netlify : chaque modification enregistrée ici est mise en ligne automatiquement.
Les demandes de devis sont envoyées par mail via Web3Forms (formulaire « Devis L'empreinte », gratuit jusqu'à 250 demandes par mois). Si le nom de domaine change, mettre à jour le champ `redirect` du formulaire dans `index.html`.
